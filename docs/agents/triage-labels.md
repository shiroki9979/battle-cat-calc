# Triage Labels

Created: 2026-10-01
Last updated: 2026-10-01

Map canonical triage roles to these tracker labels.

| Canonical role | Tracker label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer evaluation required |
| needs-info | needs-info | Waiting for reporter information |
| ready-for-agent | ready-for-agent | Fully specified for an unattended agent |
| ready-for-human | ready-for-human | Human implementation required |
| wontfix | wontfix | Will not be actioned |

When a skill names a role, apply the corresponding tracker label.
Edit the tracker-label column when the repository's vocabulary changes.
