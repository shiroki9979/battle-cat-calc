# 安全與防禦性規範

1. **輸入驗證**: 永遠不要信任外部輸入（API 請求、用戶輸入、檔案讀取）。所有輸入必須經過驗證與清理。
2. **防禦性編程**: 在執行操作前，先檢查物件是否為 null 或 undefined。
3. **最小權限原則**: 變數的作用域應儘可能縮小。優先使用 `const` 而非 `let` (TS/JS)，優先使用私有成員（Private members）。
4. **敏感資訊處理**: 絕對不可將 API Key、密碼或個人資料（PII）寫死在程式碼中。請使用環境變數。
5. **資源管理**: 確保檔案句柄、資料庫連線、記憶體在完成操作後正確釋放。
